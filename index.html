One-time setup

Connect your cloud backend

Configure Supabase in your browser. You do not need to run a server.

Supabase connection

Use only your Supabase Project URL and publishable/anon key here. Never use a service_role or secret key in a browser file.

The URL and public key are saved in this browser only. Your database permissions are enforced by Supabase Row Level Security.

Database setup

In Supabase, open SQL Editor → New query, paste the contents of setup.sql from the downloaded project and click Run. Then create the public storage bucket as described in README.md.
